# Proyecto Gestoria Front

Frontend Angular del portal documental para gestorias.

## Arranque local

```powershell
npm install
npm start -- --host 127.0.0.1 --port 4200
```

La app queda en `http://localhost:4200` y llama a la API en `http://localhost:30001`.
